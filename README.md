# LaunchCart Advanced Starter

This package is the **LaunchCart** front-end prototype (not StorePilot).

## Publish with GitHub Pages
1. Extract this ZIP on your phone or computer.
2. Open your `launchcart-platform` GitHub repository.
3. Remove the old StorePilot `index.html` and `README.md`, or replace them by uploading these files with the same names.
4. Upload the `index.html` and `README.md` from this package's `launchcart-platform` folder to the repository root.
5. Commit the changes.
6. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
7. Wait for GitHub Pages to deploy, then open `https://rana-4883.github.io/launchcart-platform/`.

## Important limitations
This is a responsive front-end demo with sample data and limited browser-side interactions. It is **not** a production Shopify competitor. Real authentication, backend, database, multi-tenant seller accounts, supplier integrations, inventory sync, live payment gateways, courier APIs, real analytics, and production security still need to be built and tested. Do not accept real customer payments or orders using this demo.
